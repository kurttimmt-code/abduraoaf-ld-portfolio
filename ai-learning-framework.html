01 / THE DESIGN CHALLENGE

Translate AI awareness into safer workplace decisions.

The capability problem

Busy professionals can be curious about AI without knowing where it helps, which information may be shared, or how to check a convincing answer. An awareness-only course is unlikely to close this gap.

  • Unsuitable tasks and inappropriate inputs
  • Vague prompting and weak quality specifications
  • Unverified outputs and unclear accountability

The proposed learning response

Teach a usable workflow: identify the work, check approval, build a purposeful prompt, verify the output, and secure human sign-off where required.

  • Short, progressive lessons for time-constrained learners
  • Application practice and consequence-based feedback
  • A printable job aid for on-the-job transfer

Design assumption: a generic, international professional-services audience. Role-specific policies, needs data and capability baselines would need validation in a real deployment.

02 / WHO THIS IS FOR

Designed around the realities of professional work.

Audience

Busy knowledge workers

Employees who draft communications, review documents, develop ideas and work with information.

Starting point

Mixed levels of AI confidence

No prior generative AI experience required; each concept is introduced before it is applied.

Design constraint

Trust and professional accountability

Use generic examples, fictional scenarios, approved-tool reminders and visible human review steps.

Performance goal: After learning, professionals should be able to select an appropriate AI-assisted task, protect inputs, shape useful prompts, verify outputs and retain accountability for the decision.
03 / MEASURABLE OBJECTIVES

Six outcomes that can be observed.

LO1

Explain

Explain generative AI and identify two limitations of generated outputs.

LO2

Select

Classify workplace tasks by suitability, approval and risk.

LO3

Construct

Create a structured prompt with goal, context, constraints and format.

LO4

Safeguard

Identify privacy, confidentiality and bias risks and appropriate controls.

LO5

Verify

Evaluate AI claims against trusted evidence before professional use.

LO6

Decide

Choose accountable actions across an AI-assisted client communication workflow.

Bloom’s progression: understand → apply → analyse → evaluate. Objectives describe intended learner performance, not measured outcomes from a completed rollout.

04 / LEARNING ARCHITECTURE

From understanding to applied judgment.

The sequence uses microlearning, worked examples, immediate feedback and authentic practice. Content builds towards a client-update scenario where learners make three linked decisions.

01Understand AI5 minNarrated explainer, concept contrasts and knowledge check
02Choose the task6 minRisk triage and workplace task classification
03Prompt with purpose7 minWorked example and interactive prompt builder
04Protect trust6 minPrivacy, accuracy and verification activities
05Apply at work5 minThree-stage client communication branching scenario
✓Assessment6 minTen scored questions and corrective feedback

Times are estimates; the complete self-paced experience is approximately 35 minutes, depending on reading and activity pace.

05 / DESIGN METHODS

Each design choice has a learning purpose.

ADDIE / ITERATION

Start with performance, not tools

Define the capability need, design aligned practice, prototype, test and refine. This is a portfolio model rather than evidence of a completed organisational needs analysis.

SCENARIO-BASED LEARNING

Practice consequential decisions

Fictional client update: protect input → verify draft → obtain approval. Each choice produces targeted feedback and a retry opportunity.

COGNITIVE LOAD + ACCESSIBILITY

Make essentials easier to use

Chunk information, pair concise visuals with narration, include subtitles and transcript, and design keyboard-friendly interactions. WCAG 2.2 AA remains an audit target, not a certification.
